# StarshipIt
* Live at https://starshipit.app
* Displays the next Starship launch countdown and flight timeline
* No ads or extra clicks for easy T-Time
* API from https://thespacedevs.com/llapi

# Mobile Install - Android / Apple
* Can be installed as a Progressive Web App for native-like operation
* Android → Open link in Chrome, tap menu, "Add to Home Screen"
* iOS → Open link in Safari, tap share, "Add to Home Screen"
